# markphelps/homebrew-tap

Homebrew casks and formulae published by [@markphelps](https://github.com/markphelps).

## Usage

```sh
brew tap markphelps/tap
brew install --cask <name>
```

Or install directly without tapping first:

```sh
brew install --cask markphelps/tap/<name>
```

Casks live in `Casks/`. They're generated by each project's release automation, so open issues or pull requests in the project's own repository rather than here.
